# Rounds

A staff loop uses the same round names as a senior loop. Each page below explains what the round measures at staff level and how to prepare for it.

| Page | Read it when |
|---|---|
| [The interview loop](interview-loop.md) | You want the whole process, from the recruiter call to the hiring committee |
| [System design](system-design.md) | You can already pass a senior design round and need to know what staff adds |
| [Project deep dive](project-deep-dive.md) | You must choose one project and defend it for 45 minutes |
| [Behavioral](behavioral.md) | Your stories are solid at senior level and need staff scope |
| [Coding](coding.md) | You are deciding how much preparation time coding deserves |

Next: the [skills](../skills/README.md) these rounds measure, and the [cheat sheets](../cheat-sheets/README.md) for the final weeks.

For full lessons on every round, see [Grokking Staff Engineer Interview](https://www.designgurus.io/course/grokking-staff-engineer-interview?utm_source=github&utm_medium=repo&utm_campaign=staff-engineer-interview&utm_content=rounds-readme).
